# 承認ワークフロー

> 元ページ: `management/workflow` ｜ 公式ページ: https://kuroco.app/ja/docs/management/workflow/

承認ワークフローでは作成された承認ワークフローの一覧を確認・追加・更新できます。

## 承認ワークフロー一覧
### 確認方法
[オペレーション] -> [承認ワークフロー]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/4675743a6d59f15a52882e6e4703ab8b.png)

### 項目説明
![Image from Gyazo](https://t.gyazo.com/teams/diverta/e308011c61b3affa0a45b258c0f50823.png)

|項目|説明|
|---|---|
|ID|ワークフローのID番号です。自動採番されます。|
|ステータス|ワークフローのステータスが[有効]または[無効]で表示されます。|
|名前|ワークフローの名前です。|
|更新日時|ワークフローの更新日時です。|

### 一括処理
![Image from Gyazo](https://t.gyazo.com/teams/diverta/b5110d754c7a3a43350fdc8b4212c358.png)

一覧の左端のチェックボックスにチェックを入れて、下記いずれかをクリックすると、選択したワークフローに対して一括で処理を行います。

|項目   |説明  |
| :--- | :--- |
|有効にする|ワークフローを有効にします。|
|無効にする|ワークフローを無効にします。|
|削除する|ワークフローを削除します。|

[基本設定]タブが表示されます。

### 項目説明
#### 基本設定
![Image from Gyazo](https://t.gyazo.com/teams/diverta/87016d2e213f38e44a8c73a711df55fa.png)

|項目   |説明  |
| :--- | :--- |
|名前|ワークフローの名前を入力します。|
|ステータス|ワークフローのステータスの有効/無効を選択します。|
|メール通知|コンテンツが承認、または差し戻された場合に、その結果をメールで通知する・しないを選択します。<br/><ul><li>通知しない：通知メールを配信しません。</li><li>通知する：通知メールを送りたいメールアドレスを欄内に記入します。複数指定するときは改行区切りで入力してください。</li></ul>|
|利用制限|承認ワークフローの機能を利用するグループを選択します。そのため、承認者、申請者の両方が選択されている必要があります。<br/>・[選択なし]の場合：対象コンテンツの編集者全員が利用できます。<br/>※グループの[権限設定]とは異なります。|

|項目   |説明  |

|コンテンツ|承認ワークフローを利用するコンテンツを選択します。|

![Image from Gyazo](https://i.gyazo.com/28622b02e531c41a87996bce0fba8cf3.png)

|項目   |説明  |
| :--- | :--- |

プレビューサイトの構築方法については、[サブサイトをプレビューサイトにする](/ja/docs/tutorials/make-the-subsite-a-preview-site/)を参照してください。

#### 申請・承認者設定
![Image from Gyazo](https://t.gyazo.com/teams/diverta/54324301b4393539fa674028f56fb07e.png)

|項目   |説明  |
| :--- | :--- |
|申請者自身の承認を許可する|無効にすると自身が申請したワークフローを自分で承認できないようになります。|
|申請者の取り下げを許可|有効にすると、申請者が自身の申請中のワークフローを取り下げることができるようになります。操作方法は[取り下げ](#取り下げ)を参照してください。|
|中間フェーズへの差し戻しを許可|有効にすると、承認者がコンテンツを最初のフェーズだけでなく、途中の承認フェーズに差し戻すことができるようになります。操作方法は[差し戻す](#差し戻す)を参照してください。|
|別ワークフローへの差し戻しを許可|有効にすると、承認者がコンテンツを現在のワークフローとは別のワークフローに差し戻すことができるようになります。操作方法は[差し戻す](#差し戻す)を参照してください。|

## 承認ワークフローフロー設定
### 確認方法
[オペレーション] -> [承認ワークフロー]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/004c16a574e5915d4501d518c15af0e0.png)

![Image from Gyazo](https://t.gyazo.com/teams/diverta/7da5e6d6d6f1f1c13a08b41c80f6294d.png)

[フロー設定]タブをクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/52a7bdd5187d17646734c4e8f15e91e3.png)

### 項目説明
![Image from Gyazo](https://t.gyazo.com/teams/diverta/cc447319be8b8730cb78077ec4a19ce5.png)

|項目   |説明  |
| :--- | :--- |
|承認グループ名|コンテンツ編集画面でワークフローを指定する時に表示される名称です。|
|[このグループを削除]ボタン|承認グループを削除します。|
|申請内容を確認するプレビューサイト|申請内容を反映するプレビューサイトを、承認グループ毎に選択します。選択したプレビューサイトには、その承認グループの承認待ちになったタイミングで申請内容が反映されます。<br/>[基本設定]タブの[プレビューサイト同期設定]で[反映するプレビューサイトをフロー毎に設定する]を選択している場合のみ表示されます。|
|一時更新権限URL|チェックをいれると、コンテンツの承認依頼時、承認依頼メールに`{$onetime_link}`がアサインされ、期限付き一時メンバーが追加されます。|
|承認者設定|承認者を設定します。<br/>・グループ：指定したグループに所属するメンバーであれば誰でも承認できる<br/>・メンバー：指定したメンバーのみ承認できる<br/>・カスタムメンバーフィルター：カスタムメンバーフィルターで指定したメンバーが承認できる|
|メール通知|チェックをいれると、コンテンツに承認ワークフローが設定されて更新された時に、承認者へ通知メールを配信します。|
|[削除]ボタン|「承認者」を削除します。|
|[追加]ボタン|「承認者」を追加します。|
|[グループ追加]ボタン|「承認グループ」を追加します。|
|[更新する]ボタン|承認ワークフローフロー設定の変更を反映します。|

## 申請中データに対する操作
承認対象コンテンツの編集画面から申請すると、申請中データが作成されます。
申請中データの画面では、承認ワークフローの設定に応じて以下の操作ができます。

![Image from Gyazo](https://i.gyazo.com/1690f0d7aa3ff4755cc16a71d6745429.png)

### 承認する
承認者が[承認する]をクリックすると、現在のフェーズの承認が完了します。
フロー設定で設定したすべてのフェーズの承認が完了すると、申請内容がコンテンツに反映されます。

### 差し戻す
承認者が[差し戻す]をクリックすると、申請を差し戻します。

[基本設定]タブの[中間フェーズへの差し戻しを許可]と[別ワークフローへの差し戻しを許可]がどちらも無効の場合は、申請者に差し戻されます。
いずれかが有効の場合は[差し戻し先を選択]ダイアログが表示され、以下から差し戻し先を選択できます。

![Image from Gyazo](https://i.gyazo.com/1266b14127f9557c309f32b8232d17f2.png)

|項目   |説明  |
| :--- | :--- |
|申請者|申請者に差し戻します。|
|差し戻し先を選択する|途中の承認フェーズを選択して差し戻します。[中間フェーズへの差し戻しを許可]が有効で、差し戻し先にできる中間フェーズがある場合に選択できます。|
|別のワークフローに移動する|申請を差し戻して、選択した別のワークフローで再処理します。[別ワークフローへの差し戻しを許可]が有効で、移動できるワークフローがある場合に選択できます。|

### 取り下げ
[基本設定]タブの[申請者の取り下げを許可]が有効な場合、申請中データの画面に[取り下げ]ボタンが表示されます。
申請者が[取り下げ]をクリックすると、自身の申請を取り下げることができます。

![Image from Gyazo](https://i.gyazo.com/6a90049efe1ba975309e8c9765bd62dd.png)

取り下げを実行すると、以下の通知・処理が行われます。

- 申請が取り下げられ、申請内容は途中保存データとして残ります。
- 現在の承認フェーズでメール通知が有効になっている承認者と、[基本設定]タブの[メール通知]で設定したメールアドレスに、「取り下げのお知らせ」メールが配信されます。
- トリガー「承認ワークフローの取り下げ後」が実行されます。詳細は[カスタム処理に利用できるトリガと変数の一覧](/ja/docs/reference/trigger-variables/#承認ワークフローの取り下げ後)を参照してください。

# ワークフロータグ

> 元ページ: `management/workflow-tags` ｜ 公式ページ: https://kuroco.app/ja/docs/management/workflow-tags/

ワークフロータグではワークフローに設定するタグの一覧を確認・追加・更新できます。
公開されたワークフロータグはワークフロー利用時に設定できます。

## ワークフロータグ一覧
### 確認方法
[オペレーション] -> [承認ワークフロー]をクリックします。  
![Image from Gyazo](https://t.gyazo.com/teams/diverta/4675743a6d59f15a52882e6e4703ab8b.png)

承認ワークフロー一覧ページから[承認ワークフロー]をクリックし、表示されたプルダウンから[ワークフロータグ]をクリックします。  
![Image from Gyazo](https://t.gyazo.com/teams/diverta/975c331cbf67eb9b11ff7f9c3e1f5a13.png)

### 項目説明
![Image from Gyazo](https://t.gyazo.com/teams/diverta/7f45fc8b201973d2144c12a68f15f983.png)

|項目   |説明  |
| :--- | :--- |
|検索|設定した条件でワークフロータグの検索ができます。|
|公開|公開、非公開のいずれかを表示します。<br/>![fetched from Gyazo](https://t.gyazo.com/teams/diverta/04844a6327ba668f74880a0f10682489.png)：公開<br/>![fetched from Gyazo](https://t.gyazo.com/teams/diverta/b483e6f928fc3319266dad8bc633f086.png)：非公開|
|タイトル|ワークフロータグのタイトルを表示します。|
|最終更新日時|ワークフロータグが最後に更新された日時を表示します。|
|並び順| 数の大きな順に並びます。一覧画面で入力して、画面下の[並び順を更新する]をクリックすると、一覧画面上で並び順だけ変更することができます。|

### 一括処理
![Image from Gyazo](https://t.gyazo.com/teams/diverta/1f7745ea46ab1d6434a4c90f04f192af.png)

一覧の左端のチェックボックスにチェックを入れて、下記いずれかをクリックすると、選択したワークフロータグに対して一括で処理を行います。

|項目   |説明  |
| :--- | :--- |
|公開にする|ワークフロータグを公開にします。|
|非公開にする|ワークフロータグを非公開にします。|
|削除する|ワークフロータグを削除します。|
|並び順を更新する|並び順フィールドに記載された順に並び順を変更します。数字のみ利用可能で、数が大きい方が上位表示されます。|
