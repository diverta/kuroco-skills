# 管理画面ログ

> 元ページ: `management/admin-log-list` ｜ 公式ページ: https://kuroco.app/ja/docs/management/admin-log-list/

管理画面ログでは管理画面での操作ログを確認できます。

## 管理画面ログの確認方法

[オペレーション] -> [ログ管理]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/bec37ecc842bbf4422d0bb77e4f6b3d2.png)

ページタイトルの上の[ログ管理]をクリックし、表示されたプルダウンの中にある[管理画面ログ]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/a4774115dfb8435cd05274e78323b9f7.png)

## 管理画面ログの項目説明
![Image from Gyazo](https://t.gyazo.com/teams/diverta/23acafbdd5df39c23e536d73d7305049.png)

### 絞り込み条件

管理画面ログではキーワードやログ日時による絞り込みと、詳細検索を用意しています。

#### キーワードによる絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/665757f781c12904ce1a68e8019073f8.png)

[キーワード] テキストボックスに検索するキーワードを入力します。キーワードを含むログを絞り込みます。

#### ログ日時による絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/64109907b3cc97e3191ce8a0e9acb9ab.png)

ログ日時の開始と終了で期間選択します。選択した期間のログを絞り込みます。  
指定できるログの期間は35日間となります。過去のログ日時を指定する場合も35日間の範囲となるように指定してください。

#### 詳細検索

[詳細検索] ボタンをクリックすると、絞り込み条件を作成できます。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/fc0a6203499f91cb0bd26944c74a5ff2.png)

絞り込み対象として指定できる項目は次の通りです。

| 項目 | 説明 | 指定できる条件 |
| :--- | :--- | :--- |
| ホスト | アクセスされたサイト | [検索条件](#検索に利用できるオペレーションについて) |
| ログレベル | メッセージの重要度を示すログレベル | [検索条件](#検索に利用できるオペレーションについて) |
| アクション | アクションの種類 | [検索条件](#検索に利用できるオペレーションについて) |
| HTTPメソッド | HTTPメソッド | [検索条件](#検索に利用できるオペレーションについて) |
| メッセージ[1]-[2] | ログの補完情報 | [検索条件](#検索に利用できるオペレーションについて) |
| URI | リクエストが行われたエンドポイントのURI   | [検索条件](#検索に利用できるオペレーションについて) |
| 送信元IPアドレス |  アクセスしたユーザーのIPアドレス | [検索条件](#検索に利用できるオペレーションについて)  | 
| メンバーID | アクセスしたユーザーのメンバーID | [検索条件](#検索に利用できるオペレーションについて)  | 
| アプリケーション・リクエストID | Kurocoのリクエスト識別子 | [検索条件](#検索に利用できるオペレーションについて)  | 
| ユーザーエージェント | アクセスしたWebブラウザのユーザーエージェント | [検索条件](#検索に利用できるオペレーションについて)  | 

詳細検索は複数の条件をAND、またはORで連結できます。ANDの場合は指定した条件すべてにマッチするデータのみを対象とします。OR条件は指定した条件のいずれかにマッチするデータを対象とします。

##### 検索に利用できるオペレーションについて

検索では次のオペレーションが指定できます。

| オペレーション   | 型 | 対象となるデータ |
| :---               | :--- | :--- |
| 含む            |  文字列 | 条件が一部に一致するデータ |
| 含まない        | 文字列 | 条件がいずれにも一致しないデータ |
| =               | 文字列・数値 | 条件に一致するデータ |
| !=              | 文字列・数値 | 条件に一致しないデータ |
| <               | 文字列・数値 | 条件未満のデータ |
| >               | 文字列・数値 | 条件より大きいデータ |
| <=              | 文字列・数値 | 条件以下のデータ |
| >=              | 文字列・数値 | 条件以上のデータ |
| で始まる         | 文字列 | 条件ではじまるデータ |
| で始まらない     | 文字列 | 条件ではじまらないデータ |
| で終わる         | 文字列 | 条件で終わるデータ |
| で終わらない     | 文字列 | 条件で終わらないデータ |
| どれかを含む     | 文字列・数値 | 条件を複数指定し、いずれかの条件に一致するデータ |
| どれも含まない   | 文字列・数値 | 条件を複数指定し、いずれの条件にも一致しないデータ |

##### 並び順について

ソートキーと表示順を選択することで検索結果の並び順を指定できます。並び順はASC（昇順。小さい方から大きくなっていく）またはDESC（降順。大きい方から小さくなっていく）を指定できます。

### ログ一覧項目

ログとして一覧されるデータの項目は次の通りです。

| 項目 | 説明 |
| :--- | :--- |
| ログ日時 |ログの記録された日時を表示します。 |
| ホスト | アクセスされたサイトを表示します。|
| ログレベル | メッセージの重要度を示すログレベルを表示します。詳細は[レベルについて](#レベルについて)を参照してください。 |
| アクション | アクションの種類を表示します。 詳細は[アクションについて](#アクションについて)を参照してください。 |
| HTTPメソッド | HTTPメソッドを表示します。 詳細は[メソッドについて](#メソッドについて)を参照してください。 |
| メッセージ[1]-[2] | ログの補完情報を表示します。数字が増えるのに伴ってより詳細な情報になります。 |
| URI | アクセスしたページのURIを表示します。 |
| 送信元IPアドレス | アクセスしたユーザーのIPアドレスを表示します。 |
| メンバーID | アクセスしたユーザーのメンバーIDを表示します。 |
| アプリケーション・リクエストID　| Kurocoのリクエスト識別子を表示します。|
| ユーザーエージェント | アクセスしたWebブラウザのユーザーエージェントを表示します。 |

#### レベルについて

メッセージの重要度を示すレベルは以下の3段階があります

- warn
- notice
- info

#### メソッドについて
- GET
- POST
- HEAD

#### アクションについて

| 項目 | 説明 |
| :--- | :--- |
| Messages | Message[1] にメッセージの詳細を表示します。 |
| Access | アクセスログ |
| RCMSForbiddenException | 例外エラー |
| UnauthorizedException | 例外エラー |
| NotFoundModuleException | 例外エラー |
| NotFoundException | 例外エラー |
| BadRequestException | 例外エラー |

# API解析

> 元ページ: `management/api-analytics` ｜ 公式ページ: https://kuroco.app/ja/docs/management/api-analytics/

[オペレーション] -> [ログ管理]をクリックします。

## KurocoFrontログの項目説明

![Image from Gyazo](https://t.gyazo.com/teams/diverta/9f832bf31c0301c33bdca8fdc6adb208.png)

### 絞り込み条件

KurocoFrontログではキーワードやログ日時による絞り込みと、詳細検索を用意しています。

#### キーワードによる絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/7251a904757a150181e86887fb5b4572.png)

[キーワード] テキストボックスに検索するキーワードを入力します。キーワードを含むログを絞り込みます。

#### ログ日時による絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/5b8fe72d4b86b4899571af6dd0466cc5.png)

ログ日時の開始と終了で期間選択します。選択した期間のログを絞り込みます。  
指定できるログの期間は35日間となります。過去のログ日時を指定する場合も35日間の範囲となるように指定してください。

#### 詳細検索

[詳細検索] ボタンをクリックすると、絞り込み条件を作成できます。
![Image from Gyazo](https://t.gyazo.com/teams/diverta/4d8ceeab5fa172b64188540f37e1e369.png)

絞り込み対象として指定できる項目は次の通りです。

| 項目 | 説明  | 指定できる条件 |
| :--- | :--- | :--- |
| キャッシュステータス | リクエストのキャッシュ提供状況 | [キャッシュステータス](#キャッシュステータスについて)
| HTTPメソッド | HTTPメソッド | [メソッドについて](#メソッドについて)
| ステータス | HTTPレスポンスステータスコード | [ステータスについて](#ステータスについて)
| レスポンス |  | [検索条件](#検索に利用できるオペレーションについて) |
| URI | リクエストが行われたエンドポイントのURI   | [検索条件](#検索に利用できるオペレーションについて) |
| 送信元IPアドレス | アクセスしたユーザーのIPアドレス   | [検索条件](#検索に利用できるオペレーションについて) |
| APIアクセストークン | リクエストと一緒に送られたアクセストークン | [検索条件](#検索に利用できるオペレーションについて) |
| 処理実行時間 | サーバーのリクエスト処理時間 | [検索条件](#検索に利用できるオペレーションについて) |
| レスポンスサイズ | HTTPリクエストのボディサイズ | [検索条件](#検索に利用できるオペレーションについて) |
| リファラー | 現在リクエストされているページへの直前のウェブページのアドレス | [検索条件](#検索に利用できるオペレーションについて) |
| 都市コード | リクエストを行ったユーザーの都市コード | [検索条件](#検索に利用できるオペレーションについて) |
| 国コード | リクエストを行ったユーザーの国コード | [検索条件](#検索に利用できるオペレーションについて) |
| 画像変換 | Fastlyの画像オプティマイザーデータ | [検索条件](#検索に利用できるオペレーションについて) |
| アプリケーション・リクエストID | Kurocoのリクエスト識別子 | [検索条件](#検索に利用できるオペレーションについて) |
| リクエストID | Fastlyのリクエスト識別子 | [検索条件](#検索に利用できるオペレーションについて) |

詳細検索は複数の条件をAND、またはORで連結できます。ANDの場合は指定した条件すべてにマッチするデータのみを対象とします。OR条件は指定した条件のいずれかにマッチするデータを対象とします。

#### 検索に利用できるオペレーションについて

検索では次のオペレーションが指定できます。

| オペレーション   | 型 | 対象となるデータ |
| :---               | :--- | :--- |
| 含む            |  文字列 | 条件が一部に一致するデータ |
| 含まない        | 文字列 | 条件がいずれにも一致しないデータ |
| =               | 文字列・数値 | 条件に一致するデータ |
| !=              | 文字列・数値 | 条件に一致しないデータ |
| <               | 文字列・数値 | 条件未満のデータ |
| >               | 文字列・数値 | 条件より大きいデータ |
| <=              | 文字列・数値 | 条件以下のデータ |
| >=              | 文字列・数値 | 条件以上のデータ |
| で始まる         | 文字列 | 条件ではじまるデータ |
| で始まらない     | 文字列 | 条件ではじまらないデータ |
| で終わる         | 文字列 | 条件で終わるデータ |
| で終わらない     | 文字列 | 条件で終わらないデータ |
| どれかを含む     | 文字列・数値 | 条件を複数指定し、いずれかの条件に一致するデータ |
| どれも含まない   | 文字列・数値 | 条件を複数指定し、いずれの条件にも一致しないデータ |

##### 並び順について

ソートキーと表示順を選択することで検索結果の並び順を指定できます。並び順はASC（昇順。小さい方から大きくなっていく）またはDESC（降順。大きい方から小さくなっていく）を指定できます。

[オペレーション] -> [ログ管理]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/bec37ecc842bbf4422d0bb77e4f6b3d2.png)

![Image from Gyazo](https://t.gyazo.com/teams/diverta/0df4fd96263a941148b19ab5d44a755c.png)

## KurocoFilesログの項目説明

![Image from Gyazo](https://t.gyazo.com/teams/diverta/e6c1b97bff5c38e5d159490f81a94dac.png)

### 絞り込み条件

KurocoFilesログではキーワードやログ日時による絞り込みと、詳細検索を用意しています。

#### キーワードによる絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/d5a7689f934141d784db227abf27d674.png)

[キーワード] テキストボックスに検索するキーワードを入力します。キーワードを含むログを絞り込みます。

#### ログ日時による絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/00b40de5ef6b236c0d8154eaf0264e9a.png)

ログ日時の開始と終了で期間選択します。選択した期間のログを絞り込みます。  
指定できるログの期間は35日間となります。過去のログ日時を指定する場合も35日間の範囲となるように指定してください。

#### 詳細検索

[詳細検索] ボタンをクリックすると、絞り込み条件を作成できます。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/75a64088dba174d33fa5420a1ca766bd.png)

絞り込み対象として指定できる項目は次の通りです。

| 項目 | 説明  | 指定できる条件 |
| :--- | :--- | :--- |
| キャッシュステータス | リクエストがキャッシュによって提供されたかどうか | [キャッシュステータスについて](#キャッシュステータスについて) |
| HTTPメソッド | HTTPメソッド | [メソッドについて](#メソッドについて) |
| ステータス | HTTPレスポンスステータスコード | [ステータスについて](#ステータスについて) |
| レスポンス |  | [検索条件](#検索に利用できるオペレーションについて) |
| URI | リクエストが行われたエンドポイントのURI | [検索条件](#検索に利用できるオペレーションについて) |
| 送信元IPアドレス | アクセスしたユーザーのIPアドレス | [検索条件](#検索に利用できるオペレーションについて) |
| APIアクセストークン | リクエストと一緒に送られたアクセストークン | [検索条件](#検索に利用できるオペレーションについて) |
| 処理実行時間 | サーバーのリクエスト処理時間 | [検索条件](#検索に利用できるオペレーションについて) |
| レスポンスサイズ | HTTPリクエストのボディサイズ | [検索条件](#検索に利用できるオペレーションについて) |

| 都市コード | リクエストを行ったユーザーの都市コード | [検索条件](#検索に利用できるオペレーションについて) |
| 国コード | リクエストを行ったユーザーの国コード | [検索条件](#検索に利用できるオペレーションについて) |

| アプリケーション・リクエストID | Kurocoのリクエスト識別子 | [検索条件](#検索に利用できるオペレーションについて) |
| リクエストID | Fastlyのリクエスト識別子 | [検索条件](#検索に利用できるオペレーションについて) |

詳細検索は複数の条件をAND、またはORで連結できます。ANDの場合は指定した条件すべてにマッチするデータのみを対象とします。OR条件は指定した条件のいずれかにマッチするデータを対象とします。

| で終わる         | 文字列 | 条件で終わるデータ |
| で終わらない     | 文字列 | 条件で終わらないデータ |

# Smartyエラーログ

> 元ページ: `management/smarty-log-list` ｜ 公式ページ: https://kuroco.app/ja/docs/management/smarty-log-list/

SmartyエラーログではAPIのリクエスト履歴が確認できます。

## Smartyエラーログの確認方法

[オペレーション] -> [ログ管理]をクリックします。 

![Image from Gyazo](https://t.gyazo.com/teams/diverta/bec37ecc842bbf4422d0bb77e4f6b3d2.png)

ページタイトルの上の[ログ管理]をクリックし、表示されたプルダウンの中にある[Smartyエラーログ]をクリックします。  

![Image from Gyazo](https://t.gyazo.com/teams/diverta/7a698c631b7952741571989f8d31d6f4.png)

## Smartyエラーログの項目説明

![Image from Gyazo](https://t.gyazo.com/teams/diverta/b0b8f1b45d47078640c1a0944b7cd3d4.png)

### 絞り込み条件

Smartyエラーログではキーワードやログ日時による絞り込みと、詳細検索を用意しています。

#### キーワードによる絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/0698d62ead29b80f7ae4d3bd9b87a61c.png)

[キーワード] テキストボックスに検索するキーワードを入力します。キーワードを含むログを絞り込みます。

#### ログ日時による絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/a8a987664cbb71c2f5151ce20789c651.png)

ログ日時の開始と終了で期間選択します。選択した期間のログを絞り込みます。  
指定できるログの期間は35日間となります。過去のログ日時を指定する場合も35日間の範囲となるように指定してください。

#### 詳細検索

[詳細検索] ボタンをクリックすると、絞り込み条件を作成できます。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/e4697b5d671f55e38c1634415a3e69b3.png)

絞り込み対象として指定できる項目は次の通りです。

|項目 | 説明 | 指定できる条件 |
| :--- | :--- | :--- |
|ホスト|リクエストの送信されたAPI domain|[検索条件](#検索に利用できるオペレーションについて)|
|ログレベル|メッセージの重要度を示すログレベル|[検索条件](#検索に利用できるオペレーションについて)|
|メッセージ[1]|メッセージ[1]の内容|[検索条件](#検索に利用できるオペレーションについて)|
|メッセージ[2]|メッセージ[2]の内容|[検索条件](#検索に利用できるオペレーションについて)|
|メッセージ[3]|メッセージ[3]の内容|[検索条件](#検索に利用できるオペレーションについて)|
|メッセージ[4]|メッセージ[4]の内容|[検索条件](#検索に利用できるオペレーションについて)|
|メッセージ[5]|メッセージ[5]の内容|[検索条件](#検索に利用できるオペレーションについて)|
|URI|リクエストが行われたエンドポイントのURI|[検索条件](#検索に利用できるオペレーションについて)|
|送信元IPアドレス|リクエストを行ったユーザーのIPアドレス|[検索条件](#検索に利用できるオペレーションについて)|
|メンバーID|リクエストを送ったメンバーのID|[検索条件](#検索に利用できるオペレーションについて)|
|アプリケーション・リクエストID| Kurocoのリクエスト識別子|[検索条件](#検索に利用できるオペレーションについて)|
|ユーザーエージェント|APIを要求したユーザーエージェント|[検索条件](#検索に利用できるオペレーションについて)|

詳細検索は複数の条件をAND、またはORで連結できます。ANDの場合は指定した条件すべてにマッチするデータのみを対象とします。OR条件は指定した条件のいずれかにマッチするデータを対象とします。

#### 検索に利用できるオペレーションについて

検索では次のオペレーションが指定できます。

| オペレーション   | 型 | 対象となるデータ |
| :---               | :--- | :--- |
| 含む            |  文字列 | 条件が一部に一致するデータ |
| 含まない        | 文字列 | 条件がいずれにも一致しないデータ |
| =               | 文字列・数値 | 条件に一致するデータ |
| !=              | 文字列・数値 | 条件に一致しないデータ |
| <               | 文字列・数値 | 条件未満のデータ |
| >               | 文字列・数値 | 条件より大きいデータ |
| <=              | 文字列・数値 | 条件以下のデータ |
| >=              | 文字列・数値 | 条件以上のデータ |
| で始まる         | 文字列 | 条件ではじまるデータ |
| で始まらない     | 文字列 | 条件ではじまらないデータ |
| で終わる         | 文字列 | 条件で終わるデータ |
| で終わらない     | 文字列 | 条件で終わらないデータ |
| どれかを含む     | 文字列・数値 | 条件を複数指定し、いずれかの条件に一致するデータ |
| どれも含まない   | 文字列・数値 | 条件を複数指定し、いずれの条件にも一致しないデータ |

##### 並び順について

ソートキーと表示順を選択することで検索結果の並び順を指定できます。並び順はASC（昇順。小さい方から大きくなっていく）またはDESC（降順。大きい方から小さくなっていく）を指定できます。
