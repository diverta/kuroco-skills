# 現行仕様メモ（自明になったら削除する）

**このファイルは保守者向けで、アプリ構築の作業中には読まなくてよい。**

SKILL.md と他の references には、**現行仕様が分かりにくい・機能が足りないことが理由で書いている記述**が混ざっている。それらは上流（Kuroco 本体・ツールの description・公式ドキュメント）が改善されれば不要になるので、**どこに何を書いたか・いつ削除できるか**をここに集約する。書いていないと、上流が直った後もスキル側に古い注記が残り続け、やがて誤情報になる。

規約:

- 対象の記述には SKILL.md 側に `<!-- spec-note: SN-x -->` を置く。`grep -rn "spec-note" skills/app-builder` で全箇所を洗い出せる
- **マーカーは表の行内に置かない**（`|` 区切りの行末に足すと列が1つ増えて表が壊れる）。表が対象なら**表の直前の独立行**に置き、どの行が対象かを併記する。段落が対象なら段落の先頭に置く
- **事実そのものは使う場所（SKILL.md 本文）に残す。** ここに移すのは「なぜ書いているか・削除条件・報告状況」だけ。事実を別ファイルに出すと実行者が読まずに誤った設計を出す
- 削除条件を満たしたら、該当記述と本エントリの両方を消す（片方だけ消さない）
