# spec-writer の暫定記述の台帳（メンテナ向け）

`skills/spec-writer` の本文に、**上流（Kuroco 側）が現在あいまい・不足しているために書いてある記述**を
置いたときは、この台帳に登録する。Kuroco 側が直れば不要になる記述なので、放置すると恒久的な負債になる。

運用ルール:

- 該当箇所は本文中に `<!-- spec-note: SN-n -->` でマークする（`grep -rn "spec-note" skills/spec-writer` で一覧できる）
- **上流が直ったら、本文の記述と台帳の行を同時に削除する。** 片方だけ消すと台帳と本文がずれる
- 安定した仕様の説明（レスポンスの形・設定の意味・評価順・ツールの制約など）はここに載せない。
  上流が改善しても誤りにならない記述には削除条件が無いため、本文にマーカー無しで書く
